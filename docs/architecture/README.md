# Architecture Decision Records (ADR)

The architecture decision records for ibc-go have moved to [`cosmos/ibc/spec/adr`](https://github.com/cosmos/ibc/tree/main/spec/adr), which holds the design decisions for the Interchain Standards and for cosmos/ibc, cosmos/ibc-go and cosmos/ibc-contracts in one numbered series.

ADRs 001 to 027 were written here and keep their numbers and file names, so `docs/architecture/adr-008-app-caller-cbs.md` is now [`spec/adr/adr-008-app-caller-cbs.md`](https://github.com/cosmos/ibc/blob/main/spec/adr/adr-008-app-caller-cbs.md). Their history before the move is in this repository.

To propose an architecture decision for ibc-go, follow the [ADR process](https://github.com/cosmos/ibc/blob/main/spec/adr/README.md#process) and open the pull request in `cosmos/ibc` with `ibc-go` in its scope.
